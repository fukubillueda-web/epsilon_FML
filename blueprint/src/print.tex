\chapter*{How to use this blueprint}
\addcontentsline{toc}{chapter}{How to use this blueprint}
The companion mathematical paper is
\path{references/epsilon_FML.tex}.  Each node records a mathematical
statement, its source, and the corresponding Lean declarations.  A node
may be implemented across several Lean modules, all listed in that node.

The exported result is Theorem~\ref{mod:main}, Langlands's First Main
Lemma for cyclic extensions of prime degree over nonarchimedean local
fields in mixed and equal characteristic.

To reproduce the checks, use the committed toolchain and dependency
manifest and run \texttt{bash scripts/VERIFY\_PUBLICATION.command}.
The checks cover the Lean build, the dependency graph, the blueprint
references, the absence of proof placeholders in completed nodes, and the
axioms and stored proof terms of the exported theorem.
